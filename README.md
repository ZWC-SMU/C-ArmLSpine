# C-ArmLSpine Dataset

## Introduction
The C-ArmLSpine dataset comprises real intraoperative X-ray images paired with corresponding 3D CBCT volumes, acquired using the Surgio-B51 mobile C-arm X-ray system (FIRST). The dataset contains 149 cases collected during routine intraoperative imaging procedures, with each case providing paired 2D X-ray views, including anteroposterior (AP) and lateral (Lat) projections, together with a corresponding 3D CBCT volume acquired from the same C-arm system. The AP and Lat projections provide complementary anatomical views of the spine, while the paired CBCT volumes provide volumetric anatomical information. As the X-ray images are directly acquired under real intraoperative conditions rather than generated from simulated projections, the dataset captures practical imaging characteristics and variations associated with clinical C-arm acquisition. In particular, the paired 2D X-ray and 3D CBCT data provide a valuable resource for research on X-ray-to-CT reconstruction, cross-modal representation learning, 3D/2D registration, and image-guided surgical navigation.
